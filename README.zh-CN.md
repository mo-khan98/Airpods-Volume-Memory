# AirPods 音量记忆（中文界面）

本项目基于 [mo-khan98/Airpods-Volume-Memory](https://github.com/mo-khan98/Airpods-Volume-Memory)，将菜单栏、设备管理、连接记录、设置和音量恢复提示翻译为简体中文。保留原项目的事件监听和音量记忆行为。

## 使用

支持 macOS 13 及以上。连接 AirPods 并调整到舒适音量，应用将记住该设备的最新音量，下次连接时自动恢复。设备数据仅保存在本机。

## 连回 Mac

打开菜单栏的 AirPods 音量记忆菜单，在已配对的耳机下点「连回 Mac」。连接成功后，应用会将该耳机设为 Mac 的声音输出。首次使用时，若 macOS 请求蓝牙权限，请允许访问。

捕获到 AirPods 的系统切换事件时，菜单会显示「已切换到 iPhone」，并提供「连回 Mac」。Mac 取得耳机音频控制权或检测到本机向耳机输出时显示「已连接 Mac」。如果应用启动后还没捕获到切换，而 Mac 只保留了蓝牙连接和默认输出，菜单会显示「播放设备未确认」。切换识别依赖 macOS 的系统日志，日志格式可能随系统版本变化。

## 键盘音量键

如果 AirPods 切回 Mac 后按键盘音量键会跳到 50%，可在菜单中点「启用键盘音量修复…」，并按 macOS 提示允许「输入监控」。授权后重新打开应用。应用只读取音量媒体键的事件来纠正这次跳变，音量键仍由 macOS 正常处理。

## 从源码构建

需要 Swift 命令行工具，在仓库目录执行：

```bash
bash scripts/build-app.sh
open dist/AirpodVolumeMacApp.app
```

构建脚本会先运行项目测试。完整功能和技术说明参见 [原始 README](README.md)。

## 高音量提醒

在“设置 > 高音量提醒”中启用并调整阈值，默认 60%。支持识别到的 AirPods 和苹果蓝牙耳机。音量超过阈值时发送一次静音通知；保持高音量期间不重复提醒，降至阈值以内后可再次触发。需要在 macOS 中允许通知，横幅显示也受专注模式和系统通知设置影响。此阈值是系统音量百分比，不代表实际声压级或安全听音时长。

静音时菜单栏显示“静音”，并暂停高音量提醒。静音状态与音量值分别处理，不会把静音误记为 0% 音量。
